# Intro
I've always found it hard to understand visitor design pattern. What is its purpose, why it is useful, and when should I use it?

# Command
Visitor pattern is similar to Command design pattern, hence we should start with understanding Command design pattern first. 

The Command design pattern transforms verbs into nouns.

# Takeaway
Visitor Design Pattern flips the Expression Problem for OO (Inheritance), making it easier to add new actions over existing types, but harder to add new types.
